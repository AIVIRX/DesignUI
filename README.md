# DockUI — Design for SwiftUI

DockUI is a native SwiftUI design environment for turning interface ideas into editable screens and production-ready SwiftUI code. It is built for rapid UI exploration: compose a screen visually, work across device presets, and continue refining the generated code in Xcode.

[View DockUI on the App Store](https://apps.apple.com/us/app/dockui-design-for-swiftui/id6496860953)

## What it demonstrates

- Native iOS and macOS development with SwiftUI
- A visual canvas with reusable UI components, modifiers, layers, and device presets
- SwiftUI code generation from editable component trees
- Template-driven workflows and design-file persistence
- Image, SF Symbol, chart, and layout tooling
- Cloud-backed community content, publishing controls, and subscriptions
- Automated regression fixtures for code generation and visual output

## Project structure

